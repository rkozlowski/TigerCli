Generated help (--help)

Metadata-driven help for the single-default-command app: name and description come from the project file via UseAssemblyMetadata, plus the two required folder options.

folder-copy --help
folder-copy
  Recursively copies a source folder into a destination parent folder.

Usage:
  folder-copy [options]

Options:
  -s, --source <value>
      Source folder to copy from.
      Required.
  -d, --destination <value>
      Parent folder that receives the copied source folder.
      Required.
  -h, --help
      Show help
  --version
      Show version
  --version-full
      Show product version
  --help-errors
      Show exit-code help
  --help-env
      Show recognized environment variables
  --non-interactive
      Disable interactive prompts
  --theme <theme>
      Select the UI theme by name
      dark | light | tiger-blue
  --color <mode>
      Select the color mode for this run
      auto | never | 16 | 256
  --no-color
      Disable color output (equivalent to --color never)
